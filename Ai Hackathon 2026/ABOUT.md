# LifeDB 數據分析報告系統 — 說明文檔

## 系統簡介

LifeDB 是一套專為安老院舍銷售團隊設計的即時數據可視化儀表板。系統基於 Google Apps Script 連接現有 Google Sheets 數據，無需改變現有工作流程，即可生成即時 Web 報告。

---

## 解決的問題

安老院舍銷售團隊每日需要跟進大量落訂個案，過往缺乏即時數據可視化工具，難以：
- 掌握團隊整體表現及個人目標達成率
- 追蹤個案來源渠道趨勢及轉化率
- 預測當月落訂數量及院費收入
- 統一管理員工假期安排
- 即時識別需要關注的員工及趨勢
- 快速生成管理報告

---

## 主要功能

| 頁面 | 功能 |
|------|------|
| 🏠 總覽 | 即時 Pulse（日均落訂、預測、工作日、請假、團隊健康指數）、⚡預警系統、KPI、趨勢圖、Top 10 |
| 📅 每月數據 | Sticky 選擇器、對比模式（任意兩月）、每日落訂圖、員工摘要（3列、狀態提示）|
| 📡 來源分析 | 月份篩選、升跌 KPI、堆疊圖、Doughnut、轉化漏斗、明細表（含變化欄）|
| 👥 員工表現 | Top 15 排名、狀態分佈 Doughnut、LV 進度（LV1-MAX）、Sparkline |
| 💰 院舍及院費 | 月份篩選、排序（升降序）、院舍詳情 Modal（月份篩選、經手員工、複製報告）|
| 🗓️ 日曆 | 月份下拉、今日 banner、統計 KPI、智能提示卡片（附建議行動）|
| 📝 報告 | 日期篩選、KPI、提醒、🤖智能建議、Top 10、WhatsApp 複製、PPT 生成 |

## 特色功能

### ⚡ 預警系統
自動識別需要關注的事項，可點擊直接查看員工詳情：
- 表現偏低員工（進度 <50% / <70%）
- 不入住率偏高月份（>22%）
- 來源渠道下跌趨勢（>15%）
- 當日多人請假提醒

### 💪 團隊健康指數
綜合評分（0-100），加權計算：
- 落訂達標率 50%
- 不入住率 30%
- 出勤率 20%

### 🏅 員工成就系統
員工詳情 Modal 內顯示成就 badge：
- 🏆 目標達成 — 達成率 ≥100%
- 👑 本月MVP — 全隊最高
- ⭐ Top 5 — 排名前五
- 📈 進步顯著 — 月均較去年提升 >15%
- 💎 高額貢獻 — 院費貢獻突出

### 🔄 轉化漏斗
來源分析頁面展示完整轉化流程：開檔 → 落訂 → 入住

### 🤖 智能分析建議
報告頁面根據數據自動生成管理建議：
- 團隊表現評估
- 個別輔導建議
- 不入住率改善方案
- 院費趨勢分析
- 來源渠道策略
- 產能預測

### 📊 一鍵生成 PPT
7 頁完整報告：封面、KPI 總覽、員工排名、來源分析、需要關注、院舍排名、報告摘要

## 技術架構

```
前端（單一 HTML 檔案）
├── Chart.js 4.4        — 圖表渲染（bar, line, doughnut, sparkline）
├── PptxGenJS 3.12      — PPT 生成
├── Custom Plugin        — 虛線預測 bar 邊框
├── 純 CSS              — 響應式佈局、暗黑模式、列印樣式、動畫
└── 純 JavaScript       — 數據處理、互動邏輯、智能分析引擎

後端（Google Apps Script）
├── Google Sheets API   — 數據來源
├── doGet()             — Web App 入口
└── JSON 輸出           — 供前端消費
```

## 使用方式

### Demo 版本（假數據）
直接用瀏覽器打開 `dashboard.html` 即可，無需任何安裝。

### 連接真實數據（Google Apps Script）
1. 在 Google Sheets 建立 Apps Script 專案
2. 部署為 Web App（執行身份：我、存取權限：知道連結的任何人）
3. 將 `dashboard.html` 中的 `DATA_SOURCE_URL` 改為 Web App URL
4. 系統自動從 Google Sheets 讀取最新數據

## 系統特點

- ✅ **零安裝**：單一 HTML 檔案，瀏覽器直接打開
- ✅ **零改動**：不影響現有 Google Sheets 工作流程
- ✅ **即時數據**：連接 Google Sheets 自動更新
- ✅ **暗黑模式**：支援深色/淺色主題切換
- ✅ **13人團隊**：3 隊架構（Michael隊 / Suki隊 / Charly隊），完整員工數據展示
- ✅ **多院舍支援**：完整院舍排名及詳情
- ✅ **互動詳情**：點擊員工/院舍名字彈出詳情及報告
- ✅ **預警系統**：自動識別需要關注的員工及趨勢
- ✅ **智能建議**：根據數據自動生成管理建議
- ✅ **對比分析**：任意月份對比、年度對比
- ✅ **一鍵匯報**：WhatsApp 文字 + PPT 一鍵生成
- ✅ **列印友好**：支援 print-friendly 排版
- ✅ **鍵盤快捷鍵**：數字 1-7 切換頁面
